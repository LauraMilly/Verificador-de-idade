# Verificador de Idade e Gênero
![Verificador de idade](https://github.com/user-attachments/assets/90913697-a58d-4732-a4f4-5c620be32a43)
## Sobre o Projeto

Este projeto captura o ano de nascimento e o gênero do usuário para calcular a idade atual e exibir uma mensagem personalizada na tela. Caso o ano inserido seja inválido, o sistema exibe um alerta de erro. A aplicação utiliza manipulação básica do DOM com JavaScript para interatividade.

## Funcionalidades

- Verifica o ano de nascimento informado pelo usuário.
- Calcula a idade com base no ano atual do sistema.
- Detecta o gênero selecionado.
- Exibe uma mensagem personalizada com nome, gênero e idade.
- Validação simples para entrada de dados.

## Tecnologias Utilizadas

- HTML
- CSS
- JavaScript

## Como Usar

1. Clone o repositório.
2. Abra o arquivo `index.html` em um navegador.
3. Insira seu nome, selecione o gênero e informe o ano de nascimento.
4. Clique no botão para verificar e visualizar o resultado.
